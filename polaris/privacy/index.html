プライバシーポリシー

POLARIS（以下「本アプリ」）は、動画素材・作品情報・投稿状況等を管理する 個人利用向け管理システムです。

1. 取得・利用するGoogleユーザーデータ

本アプリはGoogle Sheets APIを利用し、 ユーザー本人が指定したGoogleスプレッドシートに対して、 必要な範囲でデータの読み取りおよび更新を行います。

本アプリが利用するGoogleユーザーデータは、 POLARISの管理情報をGoogle Sheetsと同期する目的に限定されます。

2. 利用目的

Googleユーザーデータは、以下の目的でのみ使用します。

  • 管理対象となるGoogleスプレッドシートの読み取り
  • ユーザー本人が確定した管理情報の保存・更新
  • 同期状態、競合状態、保存結果の確認
  • 二重送信防止および同期整合性の確認

3. データの保存

本アプリは、Google Sheetsとの接続に必要なOAuth認証情報を、 ユーザー本人のローカル環境内に保存する場合があります。

本アプリがGoogleアカウントのパスワードを取得または保存することはありません。

4. 第三者への提供

本アプリは、取得したGoogleユーザーデータを第三者へ販売、提供、 または広告目的で利用しません。

Googleユーザーデータは、本アプリの管理・同期機能を提供するためにのみ使用されます。

5. データの共有

Googleユーザーデータを、開発者本人以外の第三者と共有することはありません。

6. データの削除

ユーザーは、Googleアカウントの設定から本アプリのアクセス権をいつでも取り消すことができます。

また、ローカル環境に保存されたOAuth認証情報は、 ユーザー自身で削除することができます。

7. Google API Services User Data Policy

本アプリによるGoogle APIから取得した情報の使用および他のアプリへの転送は、 Google API Services User Data Policy （Limited Use要件を含む）に従います。
